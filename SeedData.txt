===========================================

1. หลังจากวางข้อมูลตัวอย่างแล้ว ให้ทดสอบระบบด้วยการ:
   - เปิดเว็บแอป
   - ตรวจสอบว่าข้อมูลแสดงในหน้า Dashboard และ List
   - ทดสอบค้นหา กรอง และเรียงลำดับ
   - ทดสอบเพิ่ม/แก้ไข/ลบเอกสาร

2. ทดสอบฟีเจอร์แจ้งเตือนหมดอายุ:
   - รันฟังก์ชัน testDailyReminder() ใน Apps Script Editor
   - ตรวจสอบว่าได้รับอีเมลแจ้งเตือนสำหรับเอกสารที่ใกล้หมดอายุ

3. ทดสอบระบบสำรองข้อมูล:
   - รันฟังก์ชัน testWeeklyBackup() ใน Apps Script Editor
   - ตรวจสอบว่ามีไฟล์สำรองใน Google Drive

4. แก้ไข ID ให้เป็นรูปแบบ UUID ตามที่ระบบใช้:
   - ระบบจะสร้าง UUID อัตโนมัติเมื่อเพิ่มเอกสารใหม่
   - ข้อมูลตัวอย่างนี้ใช้ ID แบบง่าย เพื่อให้อ่านง่าย

หมายเหตุสำคัญ:
===========================================

- driveFileId และ driveFileUrl จะต้องว่างไว้ในข้อมูลตัวอย่าง
- เมื่อใช้งานจริง จะได้ค่าเหล่านี้จากการอัปโหลดไฟล์ผ่านเว็บแอป
